# Daily Gusle

หนังสือพิมพ์ส่วนตัวที่ค้นข่าวตามหัวข้อ เขียนสรุปจากแหล่งข่าวที่ค้นพบ พร้อมลิงก์อ้างอิงและวันที่เผยแพร่ และจัดหน้าแน่นสำหรับพิมพ์หรือบันทึกเป็น PDF

## เริ่มใช้งาน

ต้องใช้ Python 3.10+ และ API key จาก [Tavily](https://app.tavily.com) กับ OpenAI

```sh
git clone https://github.com/gussoul/daily-gusle.git
cd daily-gusle
pip install -r requirements.txt
python app.py
```

เปิด http://localhost:8000 ใส่หัวข้อข่าวและ API keys แล้วเลือก **จัดทำฉบับวันนี้**. เมื่อพร้อม เลือก **พิมพ์ / บันทึก PDF** แล้วเลือก “Save as PDF” ในหน้าต่างพิมพ์ของเบราว์เซอร์

### ตั้งค่า API key ในไฟล์ `.env` (ไม่บังคับ)

แทนที่จะกรอก key ในหน้าเว็บ สามารถตั้งค่าบนเครื่องได้:

```env
TAVILY_API_KEY=your-tavily-key
OPENAI_API_KEY=your-openai-key
OPENAI_MODEL=gpt-4o-mini
```

คัดลอกตัวอย่างข้างต้นลงในไฟล์ `.env` ที่ root ของโปรเจกต์ อย่า commit ไฟล์นี้หรือแชร์ API keys

## สิ่งที่มีในฉบับ

- ค้นข่าวช่วง 14 วันที่ผ่านมาในหัวข้อที่เลือก
- พาดหัวและเนื้อหาภาษาไทย (แก้ภาษาได้จากหน้าเว็บ) พร้อมการอ้างอิงในเนื้อหาและรายการแหล่งข่าวที่คลิกได้
- แสดงวันที่เผยแพร่จากข้อมูลแหล่งข่าว หากแหล่งข่าวไม่ระบุวันที่ จะระบุว่า “ไม่ระบุวันที่” แทนการคาดเดา
- ภาพจากผลค้นหาเมื่อมี พร้อมจัดหน้าเป็นคอลัมน์สไตล์หนังสือพิมพ์
- CSS สำหรับกระดาษ A4; พิมพ์จากเบราว์เซอร์แล้วบันทึกเป็น PDF ได้โดยไม่ต้องใช้บริการแปลงไฟล์ภายนอก
- ไม่มี Editor's Note ที่สร้างขึ้นโดยไม่จำเป็น

ข่าวและภาพมาจาก نتائجค้นเว็บ และสรุปهاด้วย AI. โปรดเปิดลิงก์ต้นฉบับเพื่อตรวจสอบก่อนเผยแพร่หรือใช้อ้างอิง; วันที่จะไม่ถูกเดาขึ้นเอง.

## API

`POST /api/newspaper` รับ `topics`, `language` וגם optional `tavily_api_key` กับ `openai_api_key`; `GET /api/health` สำหรับตรวจสถานะ. คีย์ที่ส่งผ่านหน้าเว็บใช้สำหรับคำขอนั้นเท่านั้นและไม่ได้บันทึกลงฐานข้อมูล.
